# 09 · 완료 기준

아래가 전부 참일 때 Phase 0 이 끝난다. **하나라도 아니면 Phase 1 로 넘어가지 않는다.**

## 구현

- [ ] `issued` 값이 4필드 codec 이고, 앞 세 필드에 `|` 가 못 들어간다 (01)
- [ ] 요청토큰에 **인스턴스ID 가 포함**된다 (01)
- [ ] 발급 Lua 가 멱등키를 **전체 비교**하고, 완료를 첫 필드 `D` 로 판정한다 (02)
- [ ] **완료 CAS · 보상 CAS 스크립트가 존재**하고, 무조건 `HSET`·`HDEL` 경로가 없다 (03)
- [ ] 보상 호출부가 **토큰을 넘긴다.** 멱등키만 넘기는 경로가 없다 (03)
- [ ] `-4` `-6` `-7` 이 **서로 다른 응답**으로 나간다 (04)
- [ ] PENDING 처리가 **계측만** 한다. 자동 회수 코드가 없다 (05)
- [ ] 만료 배치가 **상한 검사 스크립트**를 쓴다 (06)
- [ ] 재구성·재동기화가 **동시 실행되지 않는다** (07)

## 지표

- [ ] 위 카운터의 음수·실패 반환을 **삼키는 경로가 없다**
