### 글자 크기 분포가 문제의 핵심이다

```
11 ~ 12.5px   ████████████████████████████████████  102 건
15 ~ 20px     █████████                              27 건
22px 이상     ███                                    10 건
```

**아령 모양이다.** 아주 작은 글자가 102개, 아주 큰 게 10개, 중간이 비어 있다.

히어로가 `44px` 인데 그 아래 설명이 `11px` 다. **4배 격차**를 한 화면에서 건너뛰니까 눈이 쉴 곳이 없다.

## 2. 왜 안 예뻐 보이는가 — 원인 셋

### 원인 ① 전부 볼드다

굵기를 지정한 171곳 중 **147곳이 700 이상**이다. `400` 은 **0건**이다.

```
800  68건   ← 지금
700  79건
600  21건
500   3건
400   0건   ← 본문이 없다
```

**전부 강조하면 아무것도 강조가 안 된다.** 지금 화면은 모든 글자가 동시에 소리를 지르고 있다. 재고 숫자가 안 보이는 이유도 이거다 — 옆의 라벨도 똑같이 굵다.

### 원인 ② 같은 것이 매번 다른 값이다

padding 이 **106종**, gap 이 **18종**, radius 가 **13종**이다.

```
border-radius:  10px · 11px · 12px · 13px · 14px   ← 다섯 개가 다 있다
gap:            5px · 6px · 7px · 8px              ← 넷 다 있다
```

**11px 과 12px 은 사람 눈에 구분이 안 된다.** 구분은 안 되는데 "일정하지 않다"는 느낌만 남는다. 그게 손으로 대충 그린 인상을 만든다.

### 원인 ③ 숨 쉴 곳이 없다

- `line-height` 를 2,094줄에서 **33번**만 지정했다. 나머지는 브라우저 기본값(약 1.2)이고, **한글은 1.2에서 답답하다**
- gap 이 `6px` `8px` 같은 좁은 값에 몰려 있다 (12+14+18 = 44건이 6~10px)
- `hover` 가 **1건**, transition 이 게이지 폭 하나뿐이다 — **누를 수 있는 게 눌러도 될 것처럼 안 보인다**

## 3. 토큰 — 이 값만 쓴다

### 3-1. 글자 크기 — 8단

```
xs    11px    대시보드 캡션 전용
sm    13px    라벨 · 보조 설명
md    15px    본문 ← 사용자 화면 기본
lg    17px    강조 본문
xl    20px    카드 제목
2xl   26px    섹션 제목
3xl   34px    화면 제목 · 히어로
4xl   48px    큰 숫자 지표 전용
```

**금지: 9 · 10 · 11.5 · 12 · 12.5 · 13.5 · 14 · 14.5 · 16 · 18 · 19 · 21 · 22 · 24 · 28 · 30 · 40 · 44**

**화면군마다 기준이 다르다.**

| | 본문 기준 | 최소 |
|---|---|---|
| 사용자 화면 U1·U2·U3 | **15px** | 13px |
| 관리자 A1·A5·A6 | 13px | 13px |
| 대시보드 D1·D2·D3 | 13px | **11px** (캡션만) |

지금 사용자 화면이 대시보드와 같은 크기를 쓰고 있다. **사용자 화면 본문을 11~12 → 15 로 올리는 게 이 문서에서 가장 효과 큰 한 줄이다.**

### 3-2. 굵기 — 4단

```
400   본문 전부              ← 지금 0건. 여기가 제일 많아져야 한다
600   라벨 · 버튼 · 칩
700   카드 제목 · 섹션 제목
800   큰 숫자 지표 · 히어로만
```

**규칙: 한 화면에 `800` 은 3개 이하.**

지금 68건인 `800` 을 화면당 3개로 줄이면, 남은 셋이 진짜로 눈에 들어온다. 대시보드에서는 **초과 발급 카운터 · 잔여 재고 · p99** 정도만 `800` 이어야 한다.

### 3-3. 간격 — 4의 배수 7단

```
4 · 8 · 12 · 16 · 24 · 32 · 48
```

**금지: 2 · 3 · 5 · 6 · 7 · 9 · 10 · 11 · 13 · 14 · 18 · 20 · 22 · 26 · 34 · 44**

padding 도 같은 값에서 고른다 — `padding:16px 24px` 처럼. 106종을 이 조합으로 줄인다.

> 중간값이 필요하다고 느끼면 **스케일이 아니라 레이아웃이 틀린 것**이다. 6px 이 필요한 건 대개 요소가 너무 빽빽해서다.

### 3-4. 라운드 — 5단

```
8px     칩 · 배지 · 작은 버튼
12px    버튼 · 인풋 · 셀렉트
16px    카드
24px    모달 · 큰 패널
999px   원형
```

**금지: 6 · 9 · 10 · 11 · 13 · 14 · 18 · 22**

### 3-5. 그림자 — 3단

```
없음                                    기본. 테두리로 구분한다
0 1px 2px rgba(43,58,85,.06)            카드
0 8px 24px rgba(43,58,85,.12)           모달 · 떠 있는 것 · hover 상승
```

지금 5종이 제각각이다. **그림자는 "얼마나 떠 있나"를 말하는 언어라 단계가 섞이면 깊이가 안 읽힌다.**

### 3-6. 줄 간격

```
본문 · 설명      1.7    ← 한글은 여기가 편하다
제목 20px 이상   1.35
숫자 지표        1
```

**본문에 `line-height` 를 빠뜨리지 마라.** 지금 이게 가장 많이 빠져 있다.

### 3-7. 색 — 마크업에서 hex 를 지운다

상수는 이미 잘 만들어져 있다.

```js
NAVY='#2B3A55'  SKY='#7BA7D7'  GOLD='#C9A961'  MUTED='#94A0B0'  SUB='#5C6C86'
OK='#2F7A55'    WARN='#B0710F' DANGER='#C2384A' LINE='#E3E8EF'  SECT='#F7F9FC'
```

그런데 **마크업이 `#FFFFFF` 를 88번, `#94A0B0` 를 77번, `#E3E8EF` 를 64번 하드코딩**하고 있다. 상수를 만들어놓고 안 쓰는 상태다.

중립색에 이름을 붙여 9단으로 정리하고, **마크업의 hex 39종을 전부 상수 참조로 바꿔라.**

```
BG      #F7F9FC    페이지 바닥
SURF    #FFFFFF    카드 · 패널
SURF2   #F0F3F8    카드 안 박스
LINE    #E3E8EF    테두리
LINE2   #C8D3E2    강한 테두리 · 점선
MUTED   #94A0B0    보조 텍스트
SUB     #5C6C86    본문
NAVY    #2B3A55    제목 · 강조
```

**이걸 안 하면 다크모드를 못 만든다.** 값이 39곳에 흩어져 있으면 테마 전환이 불가능하다.

## 4. 화면별 구체 수정

### ① DEMO 컨트롤 바를 히어로 위에서 치워라 ★

`91~107줄` — U1 을 열면 **가장 먼저 보이는 게 개발자 툴바**다. `캠페인 상태` 4버튼 + `사용자 상태` 1버튼 + `발급 결과 모달` 3버튼 = 8개 버튼이 로고 바로 아래 가로로 깔려 있다.

**첫인상이 "미완성 관리 도구"가 되는 결정적 원인이다.**

```
지금                          바꿀 것
┌────────────────────┐       ┌────────────────────┐
│ 로고  네비           │       │ 로고  네비           │
├────────────────────┤       ├────────────────────┤
│ DEMO [상태][상태]…  │  ✗    │                    │
├────────────────────┤       │      히 어 로        │
│      히 어 로       │       │                    │
                              └───────────────┬────┘
                                        [⚙ 데모]  ← 우하단 고정
```

`position:fixed; right:24px; bottom:24px` 로 접히는 패널을 만들고, **기본은 닫힌 톱니 버튼 하나**만 보이게 한다. 열면 위로 펼쳐진다.

발표 때는 열어두면 되고, 스크린샷 찍을 땐 닫으면 된다.

### ② 히어로와 본문의 간극을 좁혀라

`127줄` 히어로 혜택이 `44px`, 그 아래 설명이 `14.5px`, 타임라인이 `11px` 다.

```
44px  →  34px       히어로 혜택
14.5  →  17px       히어로 설명
11    →  13px       타임라인
```

**히어로를 키워서 강조하는 게 아니라, 주변을 정리해서 강조한다.** 지금은 히어로만 크고 나머지가 뭉개져서 오히려 싸 보인다.

### ③ VIP 배지 2종이 색으로만 구분된다

`263~268줄` — `VIP 전용`(금색)과 `VIP 찬스`(하늘색)가 **둘 다 원형에 `V` 글자**다. 색만 다르다.

```
지금    ⓥ VIP 전용 (금)      ⓥ VIP 찬스 (하늘)      ← 구분 안 됨
바꿀 것 🔒 VIP 전용          ⚡ VIP 찬스             ← 형태가 다름
```

**색맹 사용자에겐 완전히 같은 배지다.** 자물쇠(등급 제한)와 번개(선착순 기회)처럼 **의미가 다르면 모양도 달라야** 한다.

### ④ 캘린더 주 라벨이 월요일 칸 위에 겹쳐 있다

`286줄` —

```html
<div style="position:absolute; left:20%; top:66%; transform:translate(-50%,-50%)">
```

5칸 그리드에서 `left:20%` 는 **월요일 셀 한가운데**다. 주간 브랜드 이름이 월요일 날짜 위에 얹혀 있다.

**그리드에 라벨 전용 열을 만들어라.**

```
지금    repeat(5, 1fr)              ← 라벨을 absolute 로 얹음
바꿀 것 150px repeat(5, 1fr)        ← 라벨이 자기 칸을 가짐
```

```
┌──────────┬─────┬─────┬─────┬─────┬─────┐
│ 브랜드위크① │  10 │  11 │ 12수 │  13 │  14 │
│ 라운드베이커리│     │     │ ┃솟음┃│     │     │
└──────────┴─────┴─────┴─────┴─────┴─────┘
   ↑ 전용 열      ━━━━━ 관통선은 5칸에만 ━━━━━
```

관통선(`top:66%`)과 솟은 수요일(`margin:-14px 0`)은 **그대로 둔다.** 라벨 위치만 고친다.

### ⑤ 쿠폰 카드가 너무 길쭉하다

`452px` 고정 높이에 3열 그리드 → 폭 `364px` × 높이 `452px`. **세로로 긴 직사각형**이다.

실물 쿠폰은 가로로 길거나 정사각형에 가깝다. 지금 비율은 쿠폰보다 **명함꽂이**처럼 보인다.

```
높이 452px → 380px
benefitStyle minHeight 56px → 44px
compact 아닐 때 padding 18px 20px 0 26px → 20px 24px 0 24px
```

좌측 레일 `8px` 때문에 좌우 패딩이 `26px / 20px` 로 비대칭인데, **레일을 감안해도 시각적 좌우 여백은 같아 보여야** 한다. `24px / 24px` 로 맞추고 레일을 `6px` 로 줄여라.

### ⑥ 누를 수 있는 게 안 눌려 보인다

`hover` 스타일이 **1건**이다. 카드·칩·달력 셀 전부 hover 반응이 없다.

```
카드          hover  →  transform: translateY(-2px)
                        box-shadow: 0 8px 24px rgba(43,58,85,.12)
                        transition: .18s ease
버튼          hover  →  배경 한 단계 진하게
달력 셀       hover  →  배경 SURF2, cursor:pointer
칩 · 토글     hover  →  테두리 LINE2
```

`prefers-reduced-motion` 은 이미 처리돼 있으니 그대로 두면 된다.

### ⑦ 종료된 혜택 카드가 6개나 회색으로 깔려 있다

`390~401줄` — 3열 × 2행으로 회색 카드 6개가 본문 하단을 차지한다. **"이 서비스가 꾸준히 돌아왔다"는 신호인데, 지금 크기로는 그냥 회색 덩어리다.**

```
지금    카드 6개 (3열 × 2행)
바꿀 것 한 줄짜리 목록 6개, 또는 가로 스크롤 칩
```

높이를 1/3 로 줄이고, 접기(`더 보기`)를 붙인다.

### ⑧ 아직 안 된 것 — 브리프에 있는데 미이행

| | 상태 |
|---|---|
| **다크모드** | **0건.** `07-design-request.md` 2-2 |
| **반응형** | `min-width:1280px` 그대로. 사용자 화면 U1·U2·U3만 필요 |

> **초과 발급 카운터와 격차 2축은 이미 구현돼 있다.** 초과 발급은 `112px` 로 크게, `db_gap`/`list_gap` 은 판정 문구까지 붙어 있다. 07 브리프의 4-1·4-2 는 **이행 완료**다.

## 5. 적용 순서

**위에서부터 효과가 크다.**

```
1  글자 굵기 800 → 400/600 정리          한 번에 가장 크게 바뀐다
2  사용자 화면 본문 11~12 → 15px
3  DEMO 바를 우하단 플로팅으로
4  간격 · 라운드 토큰으로 통일             106종 → 7종, 13종 → 5종
5  본문 line-height 1.7
6  마크업 hex 39종 → 상수 참조            다크모드의 전제
7  hover · transition
8  캘린더 라벨 전용 열
9  카드 높이 452 → 380
10 다크모드
11 반응형 (사용자 화면만)
```

**1·2번만 해도 인상이 절반은 바뀐다.** 굵기와 크기가 화면 전체를 지배하고 있어서다.

## 6. 판정 기준

작업 후 아래를 세서 확인한다. **주관이 안 들어간다.**

| | 목표 |
|---|---|
| 글자 크기 종류 | **8 이하** |
| `font-weight: 800` | 화면당 **3 이하** |
| `font-weight: 400` | 본문의 대부분 |
| gap 값 종류 | **7 이하** |
| border-radius 종류 | **5 이하** |
| 마크업 인라인 hex | **0** |
| 본문에 line-height 누락 | **0** |
| hover 스타일 | 클릭 가능한 요소 전부 |
