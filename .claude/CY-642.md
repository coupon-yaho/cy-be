## 범위 가드 — 작업 중 이걸 하고 싶어지면 멈춘다

T1 은 **계약과 저장소만** 만든다. 아래는 T1 에서 하지 않는다.

- Producer · Consumer · 발송 Adapter 구현 → T2
- 요약/실패목록 Service, 컨트롤러 `501` 제거(GET) → T3
- 재발송 로직, 컨트롤러 `501` 제거(POST) → T4
- `docs/notification/scope.md` 「범위 밖」 8항목 전부

**T1 의 완료 기준은 "T2·T3·T4 가 서로를 기다리지 않고 분기 가능한가" 하나다.**
그래서 인터페이스·enum·에러코드·미터상수까지 전부 T1 에 들어간다.

작업 중 설계도에 없는 판단이 필요해지면 → 코드 말고 `docs/notification/` 의 해당 문서를 먼저 고친다.
