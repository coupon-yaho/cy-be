# 앱 계정이 **넣기만** 하고 고치거나 지우지 못할 테이블의 정본이다.
#
# 이 파일 하나를 두 곳이 읽는다:
#   1. infra/mysql/app-grants/apply.sh   — 실제 GRANT 를 만든다
#   2. AppAccountAppendOnlyTest          — 스크립트가 만든 권한이 실제로 막는지 확인한다
#
# 목록에 있는 테이블은 SELECT · INSERT 만 받는다. 나머지는 전부 CRUD 를 받는다.
#
# ⚠️ 줄을 추가하기 전에 물을 것 — 본 코드가 그 테이블을 **정말 안 고치는가?**
#    obs 의 allowlist 와 방향이 반대다. 저쪽은 "읽어도 되는 것" 을 적고, 여기는
#    "고치면 안 되는 것" 을 적는다. 잘못 넣으면 관측이 조용히 비는 것이 아니라
#    **업무가 런타임에 1142 로 죽는다.**
#
# 형식: 한 줄에 테이블 하나. # 로 시작하는 줄과 빈 줄은 무시한다.
#       이름은 영숫자·밑줄만 허용한다(apply.sh 가 검사한다).

# ── 발급 이력 ──
#    리플레이가 상태를 재구성하는 원천이다. 한 줄이라도 바뀌면 재구성 결과가 바뀌고,
#    검증 배치는 그것을 **데이터가 틀렸다** 고 보고한다 — 원인이 이력 수정이라는 것은
#    거기 안 나온다.
#
#    본 코드에 이 테이블을 UPDATE·DELETE 하는 곳이 하나도 없다(실측). 즉 이 GRANT 는
#    동작을 바꾸지 않고 **이미 사실인 것을 강제로 만든다.**
